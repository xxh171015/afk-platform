## Problem Statement

运营查看订单列表时，只能翻页找大额订单，没法按金额筛选。

## Solution

订单列表接口 `GET /orders` 支持可选的查询参数 `minAmount`，只返回金额不低于它的订单。

## User Stories

1. As an 运营, I want to 按金额下限过滤订单列表, so that 我能快速找到大额订单
2. As an 运营, I want 不传下限时看到全部订单, so that 原来的用法不受影响
3. As an API 使用方, I want 非法的下限返回 400, so that 我能发现自己传错了参数

## Implementation Decisions

- 契约 `openapi/openapi.yaml` 的 `GET /orders` 加可选查询参数 `minAmount`（非负整数，单位分）。
- 订单模块的列表查询按 `amount >= minAmount` 过滤。

## Testing Decisions

- seams：`GET /orders` 这个 HTTP 接口。只通过 HTTP 测。
- 参考现有的订单接口测试。

## Out of Scope

- 金额上限、排序。
