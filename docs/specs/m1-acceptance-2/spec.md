# 订单状态历史

运营需要知道一个订单什么时候、经过了哪些状态，以及订单最近一次是什么时候变动的。

## 要做的

- 订单带上 `updatedAt`：新建时等于 `createdAt`，状态或备注改成功时更新。
- 新接口 `GET /orders/:id/history`：按时间顺序列出订单经过的状态和时间。
- 订单列表支持分页：`GET /orders?limit=&offset=`，可以和已有的 `status`、`customer` 过滤一起用。
- 统计接口增加 `lastUpdatedAt`：所有订单里最近一次变动的时间。

## 不做的

- 不持久化（数据仍在内存里），不改已有接口的行为和错误信息。
- 历史只记录状态变化，不记录备注变化。

契约（`openapi/openapi.yaml`）由契约票先改，其余票按契约实现。
